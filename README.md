I build web apps and dashboards, and lately I've been pulling data out of APIs and turning it into something you can read at a glance.

I'm a junior developer from Hungary, working mostly in C#, JavaScript and TypeScript.

### What you can see here

**[DevPulse](https://github.com/Kelemeng21/devpulse)** is a GitHub analytics dashboard in Next.js, React and TypeScript. Type in a username and it shows the repositories, the language split, a year of commit activity as a heatmap, and a side-by-side comparison of two developers. Four API routes of my own sit between the browser and GitHub: repositories and languages come from the REST API, the heatmap and the comparison from GraphQL. The token stays on the server, the client never sees it.

**[Christam-Website](https://github.com/Kelemeng21/Christam-Website)** is a Christmas webshop in PHP and MySQL, built by two of us: shop, cart, login and signup, gallery, contact page. The product cards, sign-in, the gallery and the contact page are mine. We worked on the database together.

**[Restful-API-Csharp](https://github.com/Kelemeng21/Restful-API-Csharp)** is a small ASP.NET Core REST API with Entity Framework: full create, read, update and delete over a zoo database.

**[UNITY0326](https://github.com/Kelemeng21/UNITY0326)** was my first Unity game, a Flappy Bird style clone with C# scripts for the flight, the pipe spawner and the scrolling ground.

The rest of the repositories are coursework: C# console and Windows Forms apps, HTML/CSS and JavaScript exercises.
